知食光 TimetoTaste 🍽️

知食光 是一個以「飲食紀錄 × 自我覺察」為核心的個人專案，希望透過清楚的飲食資訊與紀錄，幫助使用者更了解自己每天吃進了什麼，也逐步建立對身體與生活的掌控感。

這個專案同時也是我在學習 前後端整合、資料庫設計與雲端部署 過程中的實作成果。

✨ 專案特色

📊 食材與營養資訊管理

紀錄食物的熱量、蛋白質、脂肪、碳水化合物、糖、鈉、水分等

以 100g 為基準，方便比較與計算

🥗 食譜管理（CRUD）

建立、編輯、刪除食譜

將多種食材組合成完整餐點

🤖 AI營養師

串接 Gemini API，協助產生飲食建議與相關內容（持續擴充中）
